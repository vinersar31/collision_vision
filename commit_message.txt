⚡ Optimize scripts/download_examples.py with ThreadPoolExecutor

💡 **What:** Replaced the synchronous sequential image downloading in `scripts/download_examples.py` with a concurrent `concurrent.futures.ThreadPoolExecutor`. Implemented `_polite_iter` generator with a `time.sleep(2.0)` to stagger requests and added a temporary file saving logic to `_process_page` to prevent file conflicts and correctly track successfully downloaded images. Formatted the codebase using `black` and `ruff`.
🎯 **Why:** The sequential version was slow as it downloaded one image at a time, resulting in waiting on I/O.
📊 **Measured Improvement:** Baseline (synchronous) was running in roughly ~50 seconds. After the change, it executes in roughly ~25 seconds, a 2x speedup. Sleep time was safely increased from 1.5s to 2.0s to remain extremely polite to the Wikimedia Commons servers while still benefiting from concurrent HTTP requests.
